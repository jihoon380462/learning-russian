# 러시아어 노트

러시아어 알파벳을 아는 개인 학습자가 배운 표현으로 자신의 문장을 만드는 모바일 중심 학습 사이트입니다. 사이트의 방향은 [컨셉 문서](docs/site-concept.md)를 따릅니다.

사이트 주소: https://jihoon380462.github.io/learning-russian/

## 현재 범위

- 메인, 레슨, 복습, 내 문장 화면과 여섯 단계의 학습 흐름
- A1·A2의 30개 주제를 나눈 80개 정식 레슨, 수준·주제별 목록과 이어서 학습
- 강세를 표시한 단어·예문, 한국어 문법 설명과 변화표, 창작 힌트와 복습 질문
- 자유 문장 작성·저장, 작성 중인 문장과 학습 진도 유지
- 진도와 분리된 문장 복습 및 다음 복습 일정
- 브라우저의 러시아어 음성을 사용하는 예문 듣기
- 외부 AI에 전달할 교정 요청문 복사
- 브라우저 저장 데이터의 JSON 백업과 복원

[전체 커리큘럼](docs/curriculum.md)의 A1(주제 1–19, 43개 레슨)과 A2(주제 20–30, 37개 레슨)를 학습할 수 있습니다. 알파벳은 다시 가르치지 않고 발음·강세부터 시작해, 문장을 연결하여 생활 속 질문·설명·요청을 하는 단계까지 진행합니다. [A1 콘텐츠 안내](docs/a1-content.md)와 [A2 콘텐츠 안내](docs/a2-content.md)에서 주제별 레슨과 학습 범위를 확인할 수 있습니다. B1–C2 콘텐츠는 추후 추가합니다.

`취향 말하기`는 화면과 기능을 확인하기 위한 별도 샘플입니다. 정식 진도에는 포함되지 않으며, 샘플에서 직접 저장한 문장은 개인 문장으로 보관됩니다.

디자인 기준은 [확정 시안](assets/design-reference.png)입니다. 살구색·버건디·민트 구성과 연한 살구색 문장 입력창을 사용합니다.

## 실행과 배포

별도의 빌드 없이 저장소 루트의 파일을 실행합니다. 로컬에서는 저장소 디렉터리에서 다음 명령을 실행하고 `http://localhost:4173`을 엽니다.

```sh
python3 -m http.server 4173
```

검증은 Node.js에서 실행합니다.

```sh
npm test
```

GitHub Pages의 소스를 `main` 브랜치의 `/ (root)`로 지정하면 루트의 `index.html`이 배포됩니다. 페이지 이동은 해시 주소를 사용하므로 하위 화면을 새로고침해도 별도의 서버 라우팅이 필요하지 않습니다.

## 데이터와 학습 콘텐츠

문장, 진도, 복습 일정과 설정은 현재 브라우저의 `localStorage`에 저장됩니다. 기기·브라우저 간 자동 동기화는 제공하지 않습니다. 다른 기기로 옮기거나 브라우저 데이터를 지우기 전 설정에서 JSON 백업을 내려받으세요. 복원은 현재 데이터를 백업 파일의 내용으로 교체합니다.

듣기는 브라우저와 기기에 설치된 러시아어 음성에 따라 지원됩니다. AI 교정은 요청문을 복사해 사용자가 선택한 AI에서 진행하며, 사이트가 자동으로 교정 결과를 생성하지 않습니다.

정식 레슨은 [js/content.js](js/content.js)의 `lessons`에서 모읍니다. A1과 A2 자료는 `js/lessons/`에서 수준별 세 모듈로 나누어 관리합니다. A1의 기존 레슨 ID와 개인 학습 기록은 유지됩니다. 데이터 구조와 확장 방법은 [코어 구조 문서](docs/core-architecture.md)에 정리되어 있습니다. 콘텐츠 검사는 레슨 ID·수준별 주제 범위·문서 대응표·학습 자료 구조·강세 표시 누락을 확인하며, 문법과 번역의 정확성을 자동 판정하지는 않습니다.
