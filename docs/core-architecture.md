# 러시아어 학습 사이트 코어 구조

이 코어는 학습 자료를 읽고 자신의 문장을 작성·저장한 뒤 별도 일정으로 복습하는 흐름을 제공합니다. 정식 커리큘럼은 추후 추가하며, 현재 샘플은 화면과 상호작용을 확인하기 위한 자료입니다.

## 실행 방식

HTML, CSS, 네이티브 JavaScript 모듈로 구성한 정적 사이트입니다. GitHub Pages의 `main` 브랜치 `/ (root)`에서 실행하며, 서버나 번들 빌드가 필요하지 않습니다. 자산 경로는 저장소 하위 주소에서도 동작하도록 상대 경로를 사용합니다.

| 주소 | 역할 |
| --- | --- |
| `#home` | 이어서 학습, 현재 진도, 복습 및 최근 문장 |
| `#lessons` | 정식 레슨 목록과 샘플 진입 |
| `#study/preview` | 샘플의 여섯 학습 단계 |
| `#review` | 저장한 문장의 복습과 일정 관리 |
| `#sentences` | 개인 문장 목록 |

설정은 대화상자에서 열며 백업·복원을 제공합니다. 새로고침 시 해시 경로를 유지합니다.

## 콘텐츠 모델

`js/content.js`는 `lessons`, `previewLesson`, `stages`를 내보냅니다. `lessons`는 정식 레슨 배열이며 초기값은 빈 배열입니다. `previewLesson`은 `isPreview: true`인 별도 샘플입니다. 샘플을 정식 커리큘럼이나 이미 완료한 진도로 표시하지 않습니다.

레슨의 기본 형태는 다음과 같습니다.

```js
{
  id: 'stable-lesson-id',
  number: '01',
  title: '레슨 제목',
  description: '레슨 소개',
  isPreview: false,
  words: [{ ru: '강세가 표시된 러시아어', meaning: '한국어 뜻' }],
  grammar: {
    pattern: '핵심 문장 구조',
    explanation: '문법의 원리와 사용법'
  },
  examples: [{ ru: '러시아어 예문', meaning: '한국어 뜻' }],
  prompt: '자유로운 문장 창작 안내'
}
```

정식 레슨을 추가할 때는 고유하고 안정적인 `id`를 사용합니다. 진행 상태가 ID에 연결되므로 제목이나 순서를 바꿔도 ID는 유지합니다. `number`는 표시용 번호입니다. 목록의 순서는 `lessons` 배열로 조정하며, 콘텐츠 분량은 단어·예문 배열의 길이와 설명으로 조절합니다. 레슨 개수와 분량을 고정한 커리큘럼은 코어에 포함하지 않습니다.

`stages`는 Input, Understand, Repeat, Create, Feedback, Review의 순서와 화면 이름을 정의합니다. 콘텐츠를 추가할 때 기존 단어·문법을 재활용하고, 발음·강세·뜻과 예문을 함께 제공합니다. 여러 문법 항목이나 학습 난이도 같은 필드가 필요해지면 콘텐츠 모델과 해당 표시 코드를 함께 확장합니다.

## 브라우저 저장 모델

저장 키는 `russian-notebook:v1`이며 데이터에 `schemaVersion: 1`을 포함합니다.

| 항목 | 저장 내용 |
| --- | --- |
| `sentences` | 문장 ID, 원문, 뜻, 작성·수정 시각, 연결 레슨 ID |
| `drafts` | 레슨별 작성 중인 문장 |
| `progress` | 레슨별 현재 단계, 완료 여부, 수정 시각 |
| `reviews` | 복습할 문장 ID, 예정 시각, 간격과 복습 횟수 |
| `settings` | 개인 학습 설정 |

진도와 복습은 서로 다른 자료로 저장합니다. 레슨을 완료해도 문장을 자동으로 복습 완료 처리하지 않으며, 복습을 평가해도 학습 단계가 바뀌지 않습니다. 문장을 삭제하면 그 문장에 연결된 복습 항목도 삭제합니다. 같은 문장을 복습에 여러 번 추가해 중복 일정을 만들지 않습니다.

브라우저 저장소를 사용할 수 없을 때는 저장 문제를 표시하며, 브라우저 저장 데이터를 다른 기기로 자동 전송하지 않습니다. JSON 백업은 버전·필드·값·문장 참조를 검증한 후 복원합니다. 유효하지 않은 백업은 기존 데이터를 덮어쓰지 않습니다. 유효한 백업 복원은 현재 데이터를 교체합니다.

## 듣기와 선택적 AI 피드백

예문 듣기는 브라우저 음성 합성 기능과 러시아어 음성을 사용합니다. 지원되는 음성은 기기와 브라우저에 따라 달라지며, 사용할 수 없는 경우 화면에서 안내합니다. 마이크 입력이나 발음 평가 기능은 포함하지 않습니다.

AI 피드백 단계에서는 교정 요청문을 만들어 복사합니다. 사용자가 선택한 외부 AI에 전달하는 방식이며, 코어에 AI 서버나 API 키를 포함하지 않습니다. AI 응답을 흉내 내거나 교정을 학습 완료의 필수 조건으로 만들지 않습니다.

## 디자인 기준

`assets/design-reference.png`가 확정된 밝은 시안입니다. 모바일 메인에서는 큰 학습 카드, 진도·복습의 2열 카드, 최근 문장 순서를 유지합니다. 학습 화면은 참고 자료와 넓은 자유 입력 영역을 중심으로 구성하며, 입력창은 주변 카드보다 약간 짙은 연한 살구색을 사용합니다. 다크 모드는 후속 작업입니다.
