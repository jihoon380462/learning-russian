# 러시아어 학습 사이트 코어 구조

이 코어는 학습 자료를 읽고 자신의 문장을 작성·저장한 뒤 별도 일정으로 복습하는 흐름을 제공합니다. 현재 [A1 학습 콘텐츠](a1-content.md)의 19개 주제·43개 레슨과 [A2 학습 콘텐츠](a2-content.md)의 11개 주제·37개 레슨을 제공합니다. A단계 전체는 30개 주제·80개 레슨이며, B1–C2는 추후 추가합니다. 별도 샘플은 화면과 상호작용을 확인하기 위한 자료입니다.

## 실행 방식

HTML, CSS, 네이티브 JavaScript 모듈로 구성한 정적 사이트입니다. GitHub Pages의 `main` 브랜치 `/ (root)`에서 실행하며, 서버나 번들 빌드가 필요하지 않습니다. 자산 경로는 저장소 하위 주소에서도 동작하도록 상대 경로를 사용합니다.

| 주소 | 역할 |
| --- | --- |
| `#home` | 이어서 학습, 현재 진도, 복습 및 최근 문장 |
| `#lessons` | 첫 미완료 레슨의 수준에 맞춘 레슨 목록 |
| `#lessons/A1`, `#lessons/A2` | 해당 수준의 주제별 정식 레슨 목록과 샘플 진입 |
| `#study/<lesson-id>` | 선택한 정식 레슨의 여섯 학습 단계 |
| `#study/preview` | 샘플의 여섯 학습 단계 |
| `#review` | 저장한 문장의 복습과 일정 관리 |
| `#sentences` | 개인 문장 목록 |

설정은 대화상자에서 열며 백업·복원을 제공합니다. 수준 선택은 해시 링크로 이동하며, 새로고침 시 해시 경로를 유지합니다. 학습 화면의 목록 링크는 해당 레슨의 수준으로 돌아갑니다.

## 콘텐츠 모델

`js/content.js`는 정식 레슨을 모은 `lessons`, 수준별 주제 번호와 이름을 담은 `a1Topics`·`a2Topics`, 수준 선택에 사용하는 `curriculumLevels`, 별도 샘플인 `previewLesson`, 학습 단계를 정의한 `stages`를 내보냅니다. A1·A2 자료는 다음 네이티브 ES 모듈로 나눕니다.

| 파일 | 주제 |
| --- | --- |
| `js/lessons/a1-foundations.js` | 1–7: 발음·강세, 기본 문장, 명사·소유·형용사, 생활 정보 |
| `js/lessons/a1-cases.js` | 8–13: 현재형과 생활 속 격 사용 |
| `js/lessons/a1-actions.js` | 14–19: 과거·동사상·미래·이동·요청·문장 연결 |
| `js/lessons/a2-forms.js` | 20–22: 격 확장, 수량·날짜·나이, 자기 지시와 재귀 표현 |
| `js/lessons/a2-usage.js` | 23–27: 비교·상태, 동사상·이동동사, 시간과 기간 |
| `js/lessons/a2-communication.js` | 28–30: 복문, 관계절·간접화법, 생활 상황 종합 |

`curriculumLevels`의 각 항목은 `id`(A1 또는 A2), `label`, `description`, `topics`를 갖습니다. `topics`는 해당 수준의 `{ id, title }` 주제 배열이며, `lessons`의 `level`·`topic`과 연결됩니다. 수준은 A1 → A2, 각 수준 안에서는 커리큘럼 주제 순서로 배열합니다. 목록과 학습 화면은 이 정보를 사용하므로, 새 수준을 추가할 때 A1 전용 문구나 주제 배열을 별도로 복제하지 않습니다.

`previewLesson`은 `isPreview: true`인 별도 샘플입니다. 샘플을 정식 커리큘럼이나 이미 완료한 진도로 표시하지 않습니다. 기존 샘플의 ID와 개인 기록은 유지합니다.

레슨의 기본 형태는 다음과 같습니다.

```js
{
  id: 'a1-01-01',
  number: '01.1',
  level: 'A1',
  topic: 1,
  title: '레슨 제목',
  description: '레슨 소개',
  isPreview: false,
  objectives: ['레슨을 마친 뒤 할 수 있는 일'],
  words: [{ ru: '강세가 표시된 러시아어', meaning: '한국어 뜻', note: '선택적 사용 안내' }],
  grammar: {
    pattern: '핵심 문장 구조',
    explanation: '문법의 원리와 사용법',
    notes: ['구체적인 사용 규칙이나 예외'],
    table: { headers: ['항목', '형태'], rows: [['비교할 항목', '해당 형태']] }
  },
  examples: [{ ru: '러시아어 예문', meaning: '한국어 뜻' }],
  prompt: '자유로운 문장 창작 안내',
  creationHints: ['필요할 때 참고하는 구성 힌트'],
  reviewQuestions: ['배운 내용을 떠올리고 다시 활용하는 질문']
}
```

정식 레슨을 추가할 때는 고유하고 안정적인 `id`를 사용합니다. 진행 상태가 ID에 연결되므로 제목이나 순서를 바꿔도 ID는 유지합니다. `number`는 표시용 번호이고 `topic`은 [커리큘럼](curriculum.md)의 주제 번호입니다. 목록에서는 수준을 선택한 뒤 해당 수준의 주제별 레슨을 펼쳐 볼 수 있으며, 같은 주제의 레슨을 배열에서 연속해 배치합니다. 하나의 주제를 여러 레슨으로 나누되 단어·예문 수나 레슨 분량을 고정하지 않습니다.

A1을 마치면 다음 미완료 A2 레슨으로 이어서 학습할 수 있습니다. 수준별 완료 수와 전체 완료 안내는 각 레슨의 진도 기록에서 계산하며, 복습 횟수로 완료를 판단하지 않습니다. 이미 제공한 A1 레슨 ID와 샘플 ID는 유지하므로 기존 초안·문장·진도·복습 데이터를 이전 형식 그대로 불러올 수 있습니다.

`objectives`는 학습 목표, `grammar.notes`는 설명을 보충하는 규칙과 예외, 선택적인 `grammar.table`은 형태 비교에 사용합니다. 표의 각 행은 머리글과 같은 열 수를 가져야 합니다. `creationHints`는 자유 창작을 돕는 참고 자료이며 정답 목록이 아닙니다. `reviewQuestions`는 이전 내용을 떠올리고 새 문장으로 다시 활용하는 안내입니다. 이 필드들은 기존 샘플 구조에 추가한 것으로, 샘플에 없는 필드도 화면에서 처리할 수 있게 합니다.

`stages`는 Input, Understand, Repeat, Create, Feedback, Review의 순서와 화면 이름을 정의합니다. 콘텐츠를 추가할 때 기존 단어·문법을 재활용하고, 발음·강세·뜻과 예문을 함께 제공합니다. 복습 질문에 답하거나 AI 교정을 받는 것은 레슨 완료의 강제 조건이 아닙니다.

`npm test`는 저장 모델과 화면 상호작용 외에 콘텐츠 ID의 고유성, 기존 A1 ID의 보존, 문서와 일치하는 A1·A2 주제 순서와 레슨 대응표, 수준 정보, 자료 필드, 표의 열 수, 러시아어 단어·예문의 강세 표시 누락을 검사합니다. 레슨 설명과 표를 포함한 텍스트에서 한 단어 안에 라틴·키릴 문자가 섞이는 오타도 검사합니다. `ё`는 강세가 표시된 것으로 처리하고, 일부 비강세 기능어는 예외로 둡니다. 이 검사는 강세의 정확한 위치나 번역·문법의 교육적 타당성을 보증하지 않으므로 콘텐츠 변경 시 별도로 검토합니다.

## 브라우저 저장 모델

저장 키는 `russian-notebook:v1`이며 데이터에 `schemaVersion: 1`을 포함합니다.

| 항목 | 저장 내용 |
| --- | --- |
| `sentences` | 문장 ID, 원문, 뜻, 작성·수정 시각, 연결 레슨 ID |
| `drafts` | 레슨별 작성 중인 문장 |
| `progress` | 레슨별 현재 단계, 완료 여부, 수정 시각 |
| `reviews` | 복습할 문장 ID, 예정 시각, 간격과 복습 횟수 |
| `settings` | 개인 학습 설정 |

진도와 복습은 서로 다른 자료로 저장합니다. 레슨을 완료해도 문장을 자동으로 복습 완료 처리하지 않으며, 복습을 평가해도 학습 단계가 바뀌지 않습니다. 문장을 삭제하면 그 문장에 연결된 복습 항목도 삭제합니다. 같은 문장을 복습에 여러 번 추가해 중복 일정을 만들지 않습니다.

브라우저 저장소를 사용할 수 없을 때는 저장 문제를 표시하며, 브라우저 저장 데이터를 다른 기기로 자동 전송하지 않습니다. JSON 백업은 버전·필드·값·문장 참조를 검증한 후 복원합니다. 유효하지 않은 백업은 기존 데이터를 덮어쓰지 않습니다. 유효한 백업 복원은 현재 데이터를 교체합니다.

## 듣기와 선택적 AI 피드백

예문 듣기는 브라우저 음성 합성 기능과 러시아어 음성을 사용합니다. 지원되는 음성은 기기와 브라우저에 따라 달라지며, 사용할 수 없는 경우 화면에서 안내합니다. 마이크 입력이나 발음 평가 기능은 포함하지 않습니다.

AI 피드백 단계에서는 교정 요청문을 만들어 복사합니다. 사용자가 선택한 외부 AI에 전달하는 방식이며, 코어에 AI 서버나 API 키를 포함하지 않습니다. AI 응답을 흉내 내거나 교정을 학습 완료의 필수 조건으로 만들지 않습니다.

## 디자인 기준

`assets/design-reference.png`가 확정된 밝은 시안입니다. 모바일 메인에서는 큰 학습 카드, 진도·복습의 2열 카드, 최근 문장 순서를 유지합니다. 학습 화면은 참고 자료와 넓은 자유 입력 영역을 중심으로 구성하며, 입력창은 주변 카드보다 약간 짙은 연한 살구색을 사용합니다. 다크 모드는 후속 작업입니다.
