# A1 학습 콘텐츠

## 범위와 목표

[전체 커리큘럼](curriculum.md)의 A1 주제 1–19를 43개 레슨으로 나눕니다. 러시아어 알파벳을 아는 개인 학습자가 발음·강세를 확인하고, 배운 단어와 문법을 조합해 자기소개, 가족, 일과, 취향, 과거 경험과 앞으로의 계획을 짧게 표현하도록 구성했습니다.

러시아의 외국인용 러시아어 교육인 РКИ의 기초 흐름을 참고한 사이트 학습 자료입니다. 러시아 전역의 단일 공식 레슨 순서나 공인 시험의 모든 출제 범위를 의미하지 않습니다. 이후에는 [A2 학습 콘텐츠](a2-content.md)의 주제 20–30으로 이어집니다. B1–C2의 주제 31–60은 기존 커리큘럼에 유지하며, 해당 레슨은 후속 작업으로 추가합니다.

## 학습 방법

1. **단어**: 한국어 뜻과 사용 안내를 읽고, 강세를 확인하며 러시아어 표현을 듣고 소리 내어 읽습니다.
2. **이해**: 한국어 설명·규칙·변화표를 보고 예문이 만들어지는 원리를 확인합니다.
3. **반복**: 예문을 듣고 읽으며, 사람·사물·장소 등을 바꾸어 말해 봅니다.
4. **창작**: 과제와 선택적인 힌트를 참고해 자신의 상황이나 상상한 상황을 자유롭게 씁니다. 정해진 정답을 채우는 단계가 아닙니다.
5. **피드백**: 필요하면 교정 요청문을 복사해 사용자가 선택한 외부 AI에 전달합니다.
6. **복습**: 질문을 보며 규칙과 표현을 떠올리고, 저장한 문장을 별도의 일정으로 복습하며 다시 활용합니다.

레슨 목록은 주제별로 묶고, 원하는 레슨을 직접 열 수 있게 합니다. 완료 표시와 이어서 학습은 진도 기록을 사용합니다. 문장 복습 일정은 진도와 별도로 관리하며, 복습 질문이 자동 채점이나 시험 합격 판정으로 이어지지는 않습니다.

앞에서 배운 표현을 뒤에서도 재사용합니다. 처음 익힌 자기소개와 기본 문장에 소유·묘사를 더하고, 현재형과 격을 배우며 일과·장소·대상을 표현합니다. 이어서 같은 활동을 과거와 미래에 옮기고 동사상·이동·부탁·이유 연결로 확장합니다. `Меня́ зову́т…`, `Мне … лет`처럼 상황상 먼저 필요한 표현은 통째로 접한 뒤 관련 문법에서 구조를 다시 확인합니다.

## 주제별 레슨

레슨 번호는 표시용이며, `id`는 저장한 문장·초안·진도가 참조하는 고정 식별자입니다. 제목과 분량을 조정할 때도 기존 ID는 유지합니다.

| 주제 | 레슨 ID · 제목 |
| --- | --- |
| 1. 발음과 강세 익히기 | `a1-01-01` 강세를 듣고 단어의 리듬 찾기<br>`a1-01-02` 글자와 실제 소리가 달라지는 자리<br>`a1-01-03` 억양으로 알리기와 묻기 |
| 2. 인사와 자기소개 | `a1-02-01` 상대에 맞게 인사하기<br>`a1-02-02` 이름을 말하고 서로 소개하기 |
| 3. 가장 기본적인 문장 | `a1-03-01` “이것은”, “나는”으로 문장 만들기<br>`a1-03-02` 질문하고 잘못된 정보를 바로잡기 |
| 4. 명사의 성과 수 | `a1-04-01` 명사를 성과 함께 기억하기<br>`a1-04-02` 하나와 여럿을 구분하기 |
| 5. 사람과 소유 표현 | `a1-05-01` 이름 대신 대명사로 이어 말하기<br>`a1-05-02` 내 것과 네 것을 구별하기 |
| 6. 사람과 사물 묘사 | `a1-06-01` 형용사를 명사에 맞추기<br>`a1-06-02` 색깔과 크기로 내 주변 묘사하기 |
| 7. 숫자와 생활 정보 | `a1-07-01` 숫자로 가격 묻고 답하기<br>`a1-07-02` 지금 몇 시인지 말하기<br>`a1-07-03` 오늘과 내일의 요일 말하기 |
| 8. 현재 하는 일 | `a1-08-01` 지금 하는 일: 제1변화<br>`a1-08-02` 말하고 좋아하기: 제2변화<br>`a1-08-03` 자주 쓰는 변화와 공부하기 |

| 11. 가지고 있는 것과 없는 것 | `a1-11-01` 나에게 있어요: 소유와 생격<br>`a1-11-02` 없는 것과 출신 말하기<br>`a1-11-03` 책 두 권, 다섯 권 |

| 13. 누구와, 무엇으로 하는지 | `a1-13-01` 친구와 함께: 조격<br>`a1-13-02` 무엇으로 쓰고, 무슨 일을 하나요? |
| 14. 어제 있었던 일 | `a1-14-01` 어제 한 일 말하기<br>`a1-14-02` 어제 어디에 있었나요? |
| 15. 동사상의 첫 이해 | `a1-15-01` 활동과 결과를 구별하기<br>`a1-15-02` 반복하는 일과 한 번 이룬 일 |

## 자료 구성과 검증

- `js/lessons/a1-foundations.js`: 주제 1–7, 16개 레슨
- `js/lessons/a1-cases.js`: 주제 8–13, 14개 레슨
- `js/lessons/a1-actions.js`: 주제 14–19, 13개 레슨

각 레슨에는 학습 목표, 강세가 표시된 러시아어 단어와 예문, 한국어 뜻, 문법 설명과 보충 규칙, 자유 창작 안내, 선택적인 창작 힌트, 복습 질문을 제공합니다. 비교가 필요한 문법은 표를 함께 제공합니다. 데이터 구조는 [코어 구조](core-architecture.md)를 따릅니다.

`npm test`는 문서와 콘텐츠의 A1 주제 순서, 레슨 ID의 고유성, 샘플 분리, 자료 구조와 표의 열 수, 단어·예문의 강세 표시 누락을 검사합니다. 강세 위치·문법·번역·학습 순서의 타당성은 자동 검사만으로 판단할 수 없으므로 내용을 바꿀 때 별도로 검토합니다.

`취향 말하기` 샘플은 정식 A1 목록과 진도에서 분리합니다. 샘플과 기존 개인 기록은 유지하며, 저장 모델은 바꾸지 않습니다. 데이터는 현재 브라우저에 저장되고 기기 간 자동 동기화되지 않습니다. 듣기는 기기의 러시아어 음성을 사용하며, 마이크 발음 평가는 제공하지 않습니다. AI 교정은 선택적인 요청문 복사 방식입니다.
