# A2 학습 콘텐츠

## 범위와 목표

[전체 커리큘럼](curriculum.md)의 A2 주제 20–30을 37개 레슨으로 나눕니다. [A1의 43개 레슨](a1-content.md)에서 익힌 짧은 문장에 격·수량·시제·동사상의 선택과 문장 연결을 더하여, 생활 속 요구를 설명하고 필요한 정보를 묻고 상황에 맞게 요청하는 것을 목표로 합니다. A1과 A2를 합한 A단계는 30개 주제·80개 레슨입니다.

러시아의 외국인용 러시아어 교육인 РКИ의 수준별 목표를 참고해 사이트에 맞게 구성했습니다. 러시아 전역에서 같은 순서로 가르치는 공식 레슨 목록이나 공인 시험의 모든 출제 범위를 뜻하지 않습니다. B1–C2의 주제 31–60은 기존 커리큘럼에 유지하며, 해당 레슨은 후속 작업으로 제공합니다.

## 학습 방법과 A1의 재활용

단어 → 이해 → 반복 → 창작 → 선택적 피드백 → 복습의 여섯 단계를 계속 사용합니다. 단어와 예문의 강세를 확인하고 듣거나 소리 내어 읽으며, 한국어 설명과 변화표를 보고 배운 내용을 자신의 상황에 적용합니다. 창작 과제에는 정해진 정답이 없으며, 힌트는 필요할 때만 펼쳐 볼 수 있습니다.

A1에서 배운 가족·친구·집·학교·책·일과를 복수형과 여러 격으로 확장합니다. 같은 생활 장면에서 비교, 감정, 기간, 이동 경로와 이유를 덧붙이고, 마지막에는 약속·쇼핑·교통·병원·주거·여행의 문제 해결에 재사용합니다. 새로운 문법이 있는 예문은 형태와 쓰임을 설명하고, 뒤 수준의 문법을 먼저 쓰는 정중한 표현은 필요한 범위의 표현 덩어리로 안내합니다.

레슨 목록에서 A1 또는 A2를 골라 원하는 주제와 레슨을 열 수 있습니다. A1을 모두 마치면 이어서 학습할 미완료 A2 레슨을 안내합니다. A1의 기존 레슨 ID와 개인 문장·초안·진도·복습 기록은 유지합니다. 레슨 완료와 문장 복습 일정은 별개이며, AI 교정을 받거나 모든 질문에 답하는 것을 완료의 필수 조건으로 삼지 않습니다.

## 자료 구성과 검증

- `js/lessons/a2-forms.js`: 주제 20–22, 11개 레슨
- `js/lessons/a2-usage.js`: 주제 23–27, 14개 레슨
- `js/lessons/a2-communication.js`: 주제 28–30, 12개 레슨

각 레슨은 학습 목표, 강세가 표시된 러시아어 단어·예문, 한국어 뜻과 사용 안내, 문법 설명·규칙·변화표, 자유 창작 과제, 선택적인 힌트와 복습 질문으로 구성합니다. 생활 상황 종합 레슨에서는 짧은 대화와 설명을 읽고, 자신이 전하려는 요구에 맞게 내용을 바꾸어 사용합니다. 데이터 구조와 수준별 목록 구성은 [코어 구조](core-architecture.md)를 따릅니다.

`npm test`는 A1·A2 주제 순서와 문서 대응표, 수준 정보, 고유 레슨 ID와 기존 A1 ID 보존, 학습 자료 구조, 표의 열 수, 단어·예문의 강세 표시 누락과 단어 안의 라틴·키릴 문자 혼용을 검사합니다. 강세의 정확한 위치, 문법·번역·선행 학습의 타당성은 자동 검사만으로 판단할 수 없으므로 콘텐츠 변경 시 별도로 검토합니다.

듣기는 현재 기기의 러시아어 음성을 사용합니다. 마이크 발음 평가는 제공하지 않습니다. AI 피드백은 교정 요청문을 복사해 사용자가 선택한 외부 AI에 전달하는 방식입니다. 문장과 학습 기록은 현재 브라우저에 저장되며, 기기를 옮길 때는 설정에서 JSON 백업과 복원을 사용합니다.
