# 러시아어 학습 사이트 컨셉

## 기본 방향

사용자는 1명이며, 러시아어 알파벳은 이미 숙지한 상태로 가정한다.

학습의 핵심은 단어와 문법을 암기하는 데서 끝나지 않고, 배운 내용을 활용해 스스로 새로운 문장을 만들어내는 것이다.

## 학습 흐름

1. **Input**: 새로운 단어와 표현을 발음, 강세, 의미와 함께 학습한다.
2. **Understand**: 문법의 원리와 사용법을 예문을 통해 이해한다.
3. **Repeat**: 예문을 읽고 들으며 표현과 문장 구조에 익숙해진다.
4. **Create**: 학습한 내용을 조합해 자유롭게 문장을 창작한다.
5. **Feedback**: 필요할 때 AI를 활용해 문장을 교정하고 부족한 부분을 확인한다.
6. **Review**: 일정한 간격으로 이전 내용을 복습하고 다시 활용한다.

## 설계 원칙

- 실제 러시아어 교육과 언어 습득 원리를 참고해 커리큘럼을 구성한다.
- 레슨은 부담 없이 진행할 수 있도록 나누되, 학습 내용에 따라 분량을 유연하게 조절한다.
- 새로운 내용을 배울 때 이전에 학습한 단어와 문법을 지속적으로 재활용한다.
- 문장 창작은 사용자가 주도하며, 사이트는 필요한 학습 자료를 제공한다.
- 읽기, 듣기, 말하기를 중심으로 구성하고 마이크를 이용한 발음 평가 기능은 제외한다.
- 진도 관리와 복습 관리를 분리한다.
- 학습 순서와 난이도는 실제 학습 진행 상황에 따라 조정할 수 있도록 한다.

## 최종 목표

러시아어 지식을 축적하는 것뿐 아니라, 익힌 지식을 활용해 스스로 생각을 표현하고 실제 러시아어를 이해할 수 있는 능력을 기르는 것이다.
